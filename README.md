# OmniSearch

Private SearXNG-based search portal with privilege-based admin, widgets, custom engines, and theming.

Target: `https://search.imine.me`

## Status

Foundation complete:
- Role-based auth (GUEST / USER / POWER / ADMIN)
- SQLite user store + PBKDF2
- Admin shell + Users CRUD
- Standalone admin runner for development
- Docker skeleton

## Next

Parallel feature branches for engines admin, widgets, plugin installer, etc.
